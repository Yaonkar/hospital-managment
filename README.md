# Hospital Management System

A responsive hospital management application built with HTML, CSS, JavaScript, Bootstrap, Font Awesome, Chart.js, and LocalStorage.

## Features
- Authentication with registration and login
- Dashboard with analytics cards and charts
- Patient, doctor, and appointment management
- LocalStorage persistence
- Dark/light theme and export/reset tools

## Run Locally
1. Open the project folder.
2. Open index.html in your browser.
3. Create an account and start managing the system.
